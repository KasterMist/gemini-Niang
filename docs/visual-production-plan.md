# Gemini-Niang 形象与动作实施计划

## 范围
本轮交付视觉素材、可切换的半身/全身动画、动作选择与独立本地预览。不修改现有Codex插件，不将未完成的Antigravity额度适配写成已完成。
已根据用户补充找到 KasterMist/GPT-Niang，并通过 GitHub API 改名为 KasterMist/gemini-Niang，保留 T7moris/GPT-Niang 的 Fork 关系。本地 D:\Project\gemini-Niang 为独立仓库，不污染游戏 MOD 工作区。

## 设计锁定
参考 assets/reference/gemini-turnaround.png。保留猫耳、双侧发髻、呆毛、蓝紫粉渐变长发、左画面红瞳/右画面金瞳、四角星头饰、紫色星空服饰、白色褶边、渐变猫尾。全身保留鞋袜、背面蝴蝶结。

## 阶段
1. 建立基准与来源记录，生成透明背景的全身和半身动作图集。
2. 每种形态提供六种状态：待机、眨眼、招手、开心、思考、困倦。待机循环眨眼；各动作叠加轻量程序运动。
3. 提供统一角色清单、动画播放器、形态/动作/速度/大小切换、暂停、减少动态偏好。
4. 导出PNG图集和可下载GIF动画；GIF透明度有限，保留透明PNG源用于正式渲染。
5. 验证图像尺寸/alpha/帧布局、路径、动作映射、测试与浏览器视觉效果，保存结果。
6. 仓库可访问后再合并到实际fork，并保留上游版权和素材许可；不假称推送成功。

## 动画定义与限制
图集包含AI绘制的姿态/表情；程序负责循环、平移、旋转与弹跳，不冒充Live2D或完整骨骼动画。六姿态之间为离散切换，不宣称逐帧手臂连续运动。后续如需精细头发/尾巴/手臂独立运动，需要分层重绘与绑定。

## 验收
- 半身与全身可独立选择，六动作可选择；角色特征与参考图一致。
- 动画可暂停，重载保留选择；切换无路径错误。
- GIF真实导出并可解码检查帧数；动画预览不依赖在线服务。
- 未经验证的Antigravity运行集成、GitHub推送分别明确标记。
